# Contributing to Indie Game Dev

Thank you for your interest in contributing to this project! We welcome contributions of all kinds, including ideas, bug fixes, improvements, new features, documentation, and more.

## Explore the source code
Always feel free to explore the source code, fix bugs, or help contribute!
Playing the game is as simple as cloning the repository and opening the project in Godot Engine 4.4 Mono. Ensure that git submodules are initialized as well. At this point you can easily edit GDscripts, however editing & building the C# scripts may take some more work.

## Playtest the game
This game is not yet in a playable state, so cannot yet be playtested.

## How to Contribute

### Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository. Provide as much detail as possible to help us understand and reproduce the problem.

### Submitting Pull Requests

1. Fork the repository and create your branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Ensure your code follows the existing style and passes any tests.
4. Submit a pull request describing your changes and why they are needed.
5. Resolve any @CodeRabbitAI feedback.

### Code Style

Please follow the existing code style and conventions used in the project. This helps keep the codebase consistent and maintainable.
